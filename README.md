## 📌 Descripción del Proyecto
Aplicación Web tipo **SPA (Single Page Application)** desarrollada en **React + Vite** y enrutada mediante **React Router DOM**. Fusionamos las tecnologías web modernas con la estética clásica de los fichines y arcades de los 80 y 90. 

La plataforma cuenta con:
* 🕹️ **Catálogo de Juegos Retro:** Grilla interactiva con búsqueda en tiempo real y filtrado dinámico por géneros.
* 🎬 **Buscador de Cine y Series (OMDb API):** Conexión en tiempo real con la API para explorar películas, ver puntuaciones, popularidad y accesos directos a streaming.
* 👥 **Perfiles Interactivos:** Fichas individuales con minijuegos, terminales y efectos locales en JavaScript para cada integrante.
* 🌳 **Árbol de Componentes:** Vista interactiva recursiva con nodos colapsables que mapea la arquitectura del proyecto.
* 📝 **Bitácora de Desarrollo:** Línea de tiempo cronológica con filtros por etapas y tarjetas desplegables.
